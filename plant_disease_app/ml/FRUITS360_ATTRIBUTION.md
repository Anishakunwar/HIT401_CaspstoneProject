# Fruits-360 dataset attribution

This project uses grouped images from [Fruits-360](https://github.com/fruits-360/fruits-360-100x100), by Mihai Oltean, 2017–2026. The dataset is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The images are grouped into apple, banana, lime, other citrus, other fruit, and not fruit classes and resized by the model input pipeline. The dataset contains isolated produce images on a white background; real-world camera performance may differ.
